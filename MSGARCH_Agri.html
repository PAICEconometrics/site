1 1. Introduction

Modelling financial time-series has been a central topic in financial econometrics for decades. In the Master thesis “Modelling Volatility Using Markov-Switching GARCH Models” (Gluud & Jacobsen, 2021), the authors thoroughly examined whether the introduction of Markov-Switching (MS) regimes to the classic Generalized Autoregressive Conditional Heteroscedasticity (GARCH) framework improves in-sample modelling and out-of-sample risk forecasting for the S&P 500 index.

In this post, we replicate the essence of this thesis, but we pivot our focus towards an Equally Weighted Portfolio of Agricultural Commodities. Using R, we download historical data, build the GARCH and MS-GARCH models, and evaluate their abilities to measure risk via Value at Risk (VaR) and Expected Shortfall (ES).

The selected commodities: * Corn (ZC=F), Wheat (ZO=F), KC HRW Wheat (KE=F), Rough Rice (ZR=F), Feeder Cattle (GF=F), Soybean Meal (ZS=F), Soybean Oil (ZM=F), and Soybeans (ZL=F).

3 3. Model Specification

We test four models: 1. GARCH-Norm: Single-Regime GARCH(1,1) with Normal distribution. 2. GARCH-Std: Single-Regime GARCH(1,1) with Student-t distribution. 3. MS-GARCH-Norm: Markov-Switching GARCH(1,1) (2 regimes) with Normal distribution. 4. MS-GARCH-Std: Markov-Switching GARCH(1,1) (2 regimes) with Student-t distribution.

Show the code 
spec_gn <- CreateSpec(variance.spec = list(model = "sGARCH"), distribution.spec = list(distribution = "norm"))
spec_gs <- CreateSpec(variance.spec = list(model = "sGARCH"), distribution.spec = list(distribution = "std"))
spec_mn <- CreateSpec(variance.spec = list(model = c("sGARCH", "sGARCH")), distribution.spec = list(distribution = c("norm", "norm")))
spec_ms <- CreateSpec(variance.spec = list(model = c("sGARCH", "sGARCH")), distribution.spec = list(distribution = c("std", "std")))

fit_gn <- FitML(spec = spec_gn, data = ret_vec)
fit_gs <- FitML(spec = spec_gs, data = ret_vec)
fit_mn <- FitML(spec = spec_mn, data = ret_vec)
fit_ms <- FitML(spec = spec_ms, data = ret_vec)

5 5. Risk Forecasting: VaR & Expected Shortfall (ES)

With 2,264 observations, we expect approximately 113 violations at the 5% alpha level.

Model VaR Violations VaR Hit Rate (%) ES Violations
GARCH-Norm 103 4.55% 48
GARCH-Std 110 4.86% 37
MS-GARCH-Norm 114 5.04% 36
MS-GARCH-Std 112 4.95% 34

5.0.1 Risk Analysis Conclusion:

  1. VaR Violations: All models perform well in frequency (around 5%).
  2. ES Violations: The Normal models fail to capture the severity of tail events (48 violations). The MS-GARCH-Std is the winner with only 34 violations, proving that heavy-tailed distributions and regime switching together provide the most robust protection against extreme losses in commodities.

6 6. Final Thoughts

Our replication confirms the thesis’s main point: Distribution is King. For agricultural commodities, using a Student-t distribution is more critical than regime switching for overall parsimony, but combining both (MS-tGARCH) yields the most accurate risk metrics for extreme events.

# 1. Introduction

Modelling financial time-series has for decades been subject to extensive research. In the Master thesis *"Modelling Volatility Using Markov-Switching GARCH Models"* (Gluud & Jacobsen, 2021), the authors thoroughly examined whether the introduction of **Markov-Switching (MS) regimes** to the classic Generalized Autoregressive Conditional Heteroscedasticity (GARCH) framework improves in-sample modelling and out-of-sample risk forecasting for the S&P 500 index. 

This post replicates and expands that research, applying it to an **Equally Weighted Portfolio of Agricultural Commodities**. We leverage **interactive visualizations** to better understand the volatility dynamics and the transition between market regimes.

## 2.3. Autocorrelation (ACF) Diagnostics

```{r}
#| label: eda-acf-plotly
#| fig-cap: "Interactive ACF Plots"

calc_acf_df <- function(x, title) {
  a <- acf(x, plot = FALSE, lag.max = 20)
  df <- data.frame(Lag = a$lag, ACF = a$acf)
  conf <- qnorm((1 + 0.95)/2)/sqrt(a$n.used)
  return(list(df = df, conf = conf, title = title))
}

acf_ret <- calc_acf_df(ret_vec, "Returns ACF")
acf_sq <- calc_acf_df(ret_vec^2, "Squared Returns ACF")

plot_acf <- function(obj) {
  plot_ly(obj$df, x = ~Lag, y = ~ACF, type = 'bar', name = obj$title, marker = list(color = '#34495e')) %>%
    add_segments(x = 0, xend = 20, y = obj$conf, yend = obj$conf, line = list(color = 'red', dash = 'dash'), name = '95% CI') %>%
    add_segments(x = 0, xend = 20, y = -obj$conf, yend = -obj$conf, line = list(color = 'red', dash = 'dash'), showlegend = FALSE) %>%
    layout(yaxis = list(range = c(-0.2, 1)), title = obj$title)
}

subplot(plot_acf(acf_ret), plot_acf(acf_sq), nrows = 1, titleX = TRUE)
```

```{r}
qq_data <- function(res, name) {
  n <- length(res)
  df <- data.frame(
    Theoretical = qnorm(ppoints(n)),
    Sample = sort(res),
    Model = name
  )
  return(df)
}

df_qq <- rbind(qq_data(res_gn, "GARCH-Norm"), qq_data(res_gs, "GARCH-Std"))
```

# 5. Risk Assessment (VaR & Expected Shortfall)

```{r}
#| label: risk-evaluation-results

risk_gn <- Risk(fit_gn, alpha = 0.05, do.es = TRUE, do.its = TRUE)
risk_gs <- Risk(fit_gs, alpha = 0.05, do.es = TRUE, do.its = TRUE)
risk_mn <- Risk(fit_mn, alpha = 0.05, do.es = TRUE, do.its = TRUE)
risk_ms <- Risk(fit_ms, alpha = 0.05, do.es = TRUE, do.its = TRUE)

calc_v <- function(risk_obj, rets) {
  var_viol <- sum(rets < -risk_obj$VaR)
  es_viol <- sum(rets < -risk_obj$ES)
  return(c(var_viol, es_viol))
}

risk_matrix <- rbind(calc_v(risk_gn, ret_vec), calc_v(risk_gs, ret_vec), calc_v(risk_mn, ret_vec), calc_v(risk_ms, ret_vec))
rownames(risk_matrix) <- c("GARCH-Norm", "GARCH-Std", "MS-GARCH-Norm", "MS-GARCH-Std")
colnames(risk_matrix) <- c("VaR Violations", "ES Violations")

risk_matrix |> kable() |> kable_styling()
```
