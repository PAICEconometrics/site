1 Introduction

Deep Q-Learning (DQN) represents a significant advancement in reinforcement learning, combining the power of deep neural networks with Q-learning algorithms to handle high-dimensional state spaces. In the context of portfolio management, DQN offers a data-driven approach to learn optimal allocation strategies directly from market interactions without requiring explicit models of asset return distributions.

1.1 Motivation for DQN in Portfolio Optimization

Traditional portfolio optimization methods, such as mean-variance optimization, rely on assumptions about return distributions and require explicit modeling of market dynamics. DQN, conversely, learns directly from experience through trial and error, making it particularly suitable for:

  • Non-stationary markets: Adapting to changing market conditions without retraining
  • Complex state spaces: Handling multiple commodities with varying characteristics
  • Transaction costs: Learning realistic trading strategies that account for market frictions
  • Dynamic rebalancing: Determining optimal timing and magnitude of portfolio adjustments

1.2 Theoretical Foundation

1.2.1 Q-Learning Basics

Q-learning is a model-free reinforcement learning algorithm that learns the value of taking action \(a\) in state \(s\), denoted as \(Q(s,a)\). The optimal Q-function satisfies the Bellman equation:

\[ Q^*(s,a) = \mathbb{E}_{s'}\left[r + \gamma \max_{a'} Q^*(s',a') \mid s,a\right] \]

where: - \(r\) is the immediate reward - \(\gamma \in [0,1]\) is the discount factor - \(s'\) is the next state - \(a'\) is the next action

1.2.2 Deep Q-Network Architecture

DQN approximates \(Q(s,a)\) using a neural network with parameters \(\theta\):

\[ Q(s,a;\theta) \approx Q^*(s,a) \]

The network is trained by minimizing the temporal difference (TD) error:

\[ \mathcal{L}(\theta) = \mathbb{E}_{(s,a,r,s')}\left[\left(r + \gamma \max_{a'} Q(s',a';\theta^-) - Q(s,a;\theta)\right)^2\right] \]

where \(\theta^-\) are the parameters of a target network, updated periodically.

1.2.3 Key Innovations in DQN

  1. Experience Replay: Stores transitions in a replay buffer and samples mini-batches randomly, breaking temporal correlations and improving sample efficiency

  2. Target Network: Maintains a separate target network with parameters \(\theta^-\) that are updated less frequently, preventing the moving target problem

  3. \(\epsilon\)-Greedy Exploration: Balances exploration (random actions) and exploitation (greedy actions)

2.3.1 Simple Neural Network Class

class SimpleNeuralNetwork:
    """
    Lightweight neural network implementation using only NumPy.
    Implements a feedforward network with backpropagation.
    """
    
    def __init__(self, input_dim, hidden_dims, output_dim, learning_rate=0.001):
        self.learning_rate = learning_rate
        
        # Initialize weights and biases
        layer_dims = [input_dim] + hidden_dims + [output_dim]
        self.weights = []
        self.biases = []
        
        for i in range(len(layer_dims) - 1):
            # Xavier initialization
            w = np.random.randn(layer_dims[i], layer_dims[i+1]) * np.sqrt(2.0 / layer_dims[i])
            b = np.zeros((1, layer_dims[i+1]))
            self.weights.append(w)
            self.biases.append(b)
    
    def relu(self, x):
        """ReLU activation function"""
        return np.maximum(0, x)
    
    def relu_derivative(self, x):
        """Derivative of ReLU"""
        return (x > 0).astype(float)
    
    def forward(self, x):
        """Forward pass through the network"""
        self.activations = [x]
        self.z_values = []
        
        # Hidden layers with ReLU
        for i in range(len(self.weights) - 1):
            z = np.dot(self.activations[-1], self.weights[i]) + self.biases[i]
            self.z_values.append(z)
            a = self.relu(z)
            self.activations.append(a)
        
        # Output layer (linear)
        z = np.dot(self.activations[-1], self.weights[-1]) + self.biases[-1]
        self.z_values.append(z)
        self.activations.append(z)
        
        return self.activations[-1]
    
    def predict(self, x):
        """Make prediction without storing intermediate values"""
        a = x
        for i in range(len(self.weights) - 1):
            z = np.dot(a, self.weights[i]) + self.biases[i]
            a = self.relu(z)
        
        # Output layer
        output = np.dot(a, self.weights[-1]) + self.biases[-1]
        return output
    
    def backward(self, x, y_true):
        """Backward pass (backpropagation)"""
        m = x.shape[0]
        
        # Output layer gradient (MSE loss)
        delta = self.activations[-1] - y_true
        
        # Backpropagate through layers
        gradients_w = []
        gradients_b = []
        
        for i in range(len(self.weights) - 1, -1, -1):
            # Compute gradients
            grad_w = np.dot(self.activations[i].T, delta) / m
            grad_b = np.sum(delta, axis=0, keepdims=True) / m
            
            gradients_w.insert(0, grad_w)
            gradients_b.insert(0, grad_b)
            
            # Propagate delta to previous layer
            if i > 0:
                delta = np.dot(delta, self.weights[i].T) * self.relu_derivative(self.z_values[i-1])
        
        # Update weights
        for i in range(len(self.weights)):
            self.weights[i] -= self.learning_rate * gradients_w[i]
            self.biases[i] -= self.learning_rate * gradients_b[i]
        
        # Return loss
        loss = np.mean((self.activations[-1] - y_true) ** 2)
        return loss
    
    def get_weights(self):
        """Get copy of weights"""
        return [w.copy() for w in self.weights], [b.copy() for b in self.biases]
    
    def set_weights(self, weights, biases):
        """Set weights"""
        self.weights = [w.copy() for w in weights]
        self.biases = [b.copy() for b in biases]

class PortfolioEnv:
    """
    Reinforcement Learning environment for portfolio allocation.
    
    State: [portfolio_weights, recent_returns, rolling_volatilities]
    Action: Discrete action space representing different allocation strategies
    Reward: Risk-adjusted return (Sharpe ratio)
    """
    
    def __init__(self, returns_data, initial_capital=100000, transaction_cost=0.001, lookback=20):
        self.returns_data = returns_data
        self.n_assets = returns_data.shape[1]
        self.n_steps = returns_data.shape[0]
        self.initial_capital = initial_capital
        self.transaction_cost = transaction_cost
        self.lookback = lookback
        
        # Define action space: 9 discrete portfolio allocations
        self.n_actions = 9
        self.action_space = self._create_action_space()
        
        # State space dimension
        self.state_dim = self.n_assets * 3  # weights + returns + volatilities
        
        self.reset()
    
    def _create_action_space(self):
        """Define discrete allocation strategies"""
        if self.n_assets == 3:
            actions = [
                [0.33, 0.33, 0.34],  # Equal weight
                [0.60, 0.20, 0.20],  # Corn heavy
                [0.20, 0.60, 0.20],  # Wheat heavy
                [0.20, 0.20, 0.60],  # Soybean heavy
                [0.50, 0.50, 0.00],  # Corn-Wheat
                [0.50, 0.00, 0.50],  # Corn-Soybean
                [0.00, 0.50, 0.50],  # Wheat-Soybean
                [1.00, 0.00, 0.00],  # 100% Corn
                [0.00, 1.00, 0.00],  # 100% Wheat
            ]
        return np.array(actions)
    
    def reset(self):
        """Reset environment to initial state"""
        self.current_step = self.lookback
        self.portfolio_value = self.initial_capital
        self.portfolio_weights = np.array([1.0/self.n_assets] * self.n_assets)
        self.done = False
        return self._get_state()
    
    def _get_state(self):
        """
        Construct state vector:
        - Current portfolio weights
        - Recent returns (lookback window)
        - Rolling volatilities
        """
        if self.current_step < self.lookback:
            recent_returns = np.zeros(self.n_assets)
            rolling_vol = np.zeros(self.n_assets)
        else:
            recent_data = self.returns_data[self.current_step-self.lookback:self.current_step]
            recent_returns = np.mean(recent_data, axis=0)
            rolling_vol = np.std(recent_data, axis=0)
        
        state = np.concatenate([
            self.portfolio_weights,
            recent_returns,
            rolling_vol
        ])
        
        return state
    
    def step(self, action_idx):
        """Execute one time step"""
        # Get new weights from action
        new_weights = self.action_space[action_idx]
        
        # Calculate transaction costs
        weight_changes = np.abs(new_weights - self.portfolio_weights)
        costs = self.portfolio_value * np.sum(weight_changes) * self.transaction_cost
        
        # Update weights
        self.portfolio_weights = new_weights
        
        # Get next period returns
        next_returns = self.returns_data[self.current_step]
        
        # Calculate portfolio return
        portfolio_return = np.dot(self.portfolio_weights, next_returns)
        
        # Update portfolio value
        self.portfolio_value = self.portfolio_value * (1 + portfolio_return) - costs
        
        # Calculate reward
        reward = portfolio_return - (costs / self.portfolio_value)
        
        # Move to next step
        self.current_step += 1
        
        # Check if episode is done
        if self.current_step >= self.n_steps - 1:
            self.done = True
        
        next_state = self._get_state()
        
        return next_state, reward, self.done, {
            'portfolio_value': self.portfolio_value,
            'portfolio_return': portfolio_return,
            'costs': costs,
            'weights': self.portfolio_weights.copy()
        }

class DQNAgent:
    """
    Deep Q-Network agent for portfolio optimization.
    Uses SimpleNeuralNetwork instead of TensorFlow/PyTorch.
    """
    
    def __init__(self, state_dim, n_actions, learning_rate=0.001, gamma=0.95,
                 epsilon_start=1.0, epsilon_end=0.01, epsilon_decay=0.995):
        self.state_dim = state_dim
        self.n_actions = n_actions
        self.learning_rate = learning_rate
        self.gamma = gamma
        
        # Exploration parameters
        self.epsilon = epsilon_start
        self.epsilon_end = epsilon_end
        self.epsilon_decay = epsilon_decay
        
        # Experience replay
        self.memory = deque(maxlen=10000)
        self.batch_size = 32
        
        # Build networks
        self.model = SimpleNeuralNetwork(
            input_dim=state_dim,
            hidden_dims=[128, 64, 32],
            output_dim=n_actions,
            learning_rate=learning_rate
        )
        
        self.target_model = SimpleNeuralNetwork(
            input_dim=state_dim,
            hidden_dims=[128, 64, 32],
            output_dim=n_actions,
            learning_rate=learning_rate
        )
        
        self.update_target_model()
        
        # Training history
        self.training_history = {
            'episode': [],
            'reward': [],
            'epsilon': [],
            'loss': []
        }
    
    def update_target_model(self):
        """Copy weights from main model to target model"""
        weights, biases = self.model.get_weights()
        self.target_model.set_weights(weights, biases)
    
    def remember(self, state, action, reward, next_state, done):
        """Store experience in replay buffer"""
        self.memory.append((state, action, reward, next_state, done))
    
    def act(self, state, training=True):
        """Choose action using epsilon-greedy policy"""
        if training and np.random.random() < self.epsilon:
            return np.random.randint(self.n_actions)
        
        q_values = self.model.predict(state.reshape(1, -1))
        return np.argmax(q_values[0])
    
    def replay(self):
        """Train on random mini-batch from experience replay buffer"""
        if len(self.memory) < self.batch_size:
            return 0.0
        
        # Sample random mini-batch
        minibatch = random.sample(self.memory, self.batch_size)
        
        states = np.array([t[0] for t in minibatch])
        actions = np.array([t[1] for t in minibatch])
        rewards = np.array([t[2] for t in minibatch])
        next_states = np.array([t[3] for t in minibatch])
        dones = np.array([t[4] for t in minibatch])
        
        # Compute Q-values for current states
        current_q_values = self.model.predict(states)
        
        # Compute target Q-values using target network
        next_q_values = self.target_model.predict(next_states)
        
        # Calculate TD targets
        targets = current_q_values.copy()
        for i in range(self.batch_size):
            if dones[i]:
                targets[i, actions[i]] = rewards[i]
            else:
                targets[i, actions[i]] = rewards[i] + self.gamma * np.max(next_q_values[i])
        
        # Train model
        _ = self.model.forward(states)
        loss = self.model.backward(states, targets)
        
        # Decay epsilon
        if self.epsilon > self.epsilon_end:
            self.epsilon *= self.epsilon_decay
        
        return loss

# Introduction

Deep Q-Learning (DQN) represents a significant advancement in reinforcement learning, combining the power of deep neural networks with Q-learning algorithms to handle high-dimensional state spaces. In the context of portfolio management, DQN offers a data-driven approach to learn optimal allocation strategies directly from market interactions without requiring explicit models of asset return distributions.

## Motivation for DQN in Portfolio Optimization

Traditional portfolio optimization methods, such as mean-variance optimization, rely on assumptions about return distributions and require explicit modeling of market dynamics. DQN, conversely, learns directly from experience through trial and error, making it particularly suitable for:

- **Non-stationary markets**: Adapting to changing market conditions without retraining
- **Complex state spaces**: Handling multiple commodities with varying characteristics
- **Transaction costs**: Learning realistic trading strategies that account for market frictions
- **Dynamic rebalancing**: Determining optimal timing and magnitude of portfolio adjustments

## Theoretical Foundation

### Q-Learning Basics

Q-learning is a model-free reinforcement learning algorithm that learns the value of taking action $a$ in state $s$, denoted as $Q(s,a)$. The optimal Q-function satisfies the Bellman equation:

$$
Q^*(s,a) = \mathbb{E}_{s'}\left[r + \gamma \max_{a'} Q^*(s',a') \mid s,a\right]
$$

where:
- $r$ is the immediate reward
- $\gamma \in [0,1]$ is the discount factor
- $s'$ is the next state
- $a'$ is the next action

### Deep Q-Network Architecture

DQN approximates $Q(s,a)$ using a neural network with parameters $\theta$:

$$
Q(s,a;\theta) \approx Q^*(s,a)
$$

The network is trained by minimizing the temporal difference (TD) error:

$$
\mathcal{L}(\theta) = \mathbb{E}_{(s,a,r,s')}\left[\left(r + \gamma \max_{a'} Q(s',a';\theta^-) - Q(s,a;\theta)\right)^2\right]
$$

where $\theta^-$ are the parameters of a target network, updated periodically.

### Key Innovations in DQN

1. **Experience Replay**: Stores transitions in a replay buffer and samples mini-batches randomly, breaking temporal correlations and improving sample efficiency

2. **Target Network**: Maintains a separate target network with parameters $\theta^-$ that are updated less frequently, preventing the moving target problem

3. **$\epsilon$-Greedy Exploration**: Balances exploration (random actions) and exploitation (greedy actions)

```{python neural-network}
#| label: neural-network-class

class SimpleNeuralNetwork:
    """
    Lightweight neural network implementation using only NumPy.
    Implements a feedforward network with backpropagation.
    """
    
    def __init__(self, input_dim, hidden_dims, output_dim, learning_rate=0.001):
        self.learning_rate = learning_rate
        
        # Initialize weights and biases
        layer_dims = [input_dim] + hidden_dims + [output_dim]
        self.weights = []
        self.biases = []
        
        for i in range(len(layer_dims) - 1):
            # Xavier initialization
            w = np.random.randn(layer_dims[i], layer_dims[i+1]) * np.sqrt(2.0 / layer_dims[i])
            b = np.zeros((1, layer_dims[i+1]))
            self.weights.append(w)
            self.biases.append(b)
    
    def relu(self, x):
        """ReLU activation function"""
        return np.maximum(0, x)
    
    def relu_derivative(self, x):
        """Derivative of ReLU"""
        return (x > 0).astype(float)
    
    def forward(self, x):
        """Forward pass through the network"""
        self.activations = [x]
        self.z_values = []
        
        # Hidden layers with ReLU
        for i in range(len(self.weights) - 1):
            z = np.dot(self.activations[-1], self.weights[i]) + self.biases[i]
            self.z_values.append(z)
            a = self.relu(z)
            self.activations.append(a)
        
        # Output layer (linear)
        z = np.dot(self.activations[-1], self.weights[-1]) + self.biases[-1]
        self.z_values.append(z)
        self.activations.append(z)
        
        return self.activations[-1]
    
    def predict(self, x):
        """Make prediction without storing intermediate values"""
        a = x
        for i in range(len(self.weights) - 1):
            z = np.dot(a, self.weights[i]) + self.biases[i]
            a = self.relu(z)
        
        # Output layer
        output = np.dot(a, self.weights[-1]) + self.biases[-1]
        return output
    
    def backward(self, x, y_true):
        """Backward pass (backpropagation)"""
        m = x.shape[0]
        
        # Output layer gradient (MSE loss)
        delta = self.activations[-1] - y_true
        
        # Backpropagate through layers
        gradients_w = []
        gradients_b = []
        
        for i in range(len(self.weights) - 1, -1, -1):
            # Compute gradients
            grad_w = np.dot(self.activations[i].T, delta) / m
            grad_b = np.sum(delta, axis=0, keepdims=True) / m
            
            gradients_w.insert(0, grad_w)
            gradients_b.insert(0, grad_b)
            
            # Propagate delta to previous layer
            if i > 0:
                delta = np.dot(delta, self.weights[i].T) * self.relu_derivative(self.z_values[i-1])
        
        # Update weights
        for i in range(len(self.weights)):
            self.weights[i] -= self.learning_rate * gradients_w[i]
            self.biases[i] -= self.learning_rate * gradients_b[i]
        
        # Return loss
        loss = np.mean((self.activations[-1] - y_true) ** 2)
        return loss
    
    def get_weights(self):
        """Get copy of weights"""
        return [w.copy() for w in self.weights], [b.copy() for b in self.biases]
    
    def set_weights(self, weights, biases):
        """Set weights"""
        self.weights = [w.copy() for w in weights]
        self.biases = [b.copy() for b in biases]

print("✅ Neural Network class created")
```

```{python trading-env}
#| label: trading-environment

class PortfolioEnv:
    """
    Reinforcement Learning environment for portfolio allocation.
    
    State: [portfolio_weights, recent_returns, rolling_volatilities]
    Action: Discrete action space representing different allocation strategies
    Reward: Risk-adjusted return (Sharpe ratio)
    """
    
    def __init__(self, returns_data, initial_capital=100000, transaction_cost=0.001, lookback=20):
        self.returns_data = returns_data
        self.n_assets = returns_data.shape[1]
        self.n_steps = returns_data.shape[0]
        self.initial_capital = initial_capital
        self.transaction_cost = transaction_cost
        self.lookback = lookback
        
        # Define action space: 9 discrete portfolio allocations
        self.n_actions = 9
        self.action_space = self._create_action_space()
        
        # State space dimension
        self.state_dim = self.n_assets * 3  # weights + returns + volatilities
        
        self.reset()
    
    def _create_action_space(self):
        """Define discrete allocation strategies"""
        if self.n_assets == 3:
            actions = [
                [0.33, 0.33, 0.34],  # Equal weight
                [0.60, 0.20, 0.20],  # Corn heavy
                [0.20, 0.60, 0.20],  # Wheat heavy
                [0.20, 0.20, 0.60],  # Soybean heavy
                [0.50, 0.50, 0.00],  # Corn-Wheat
                [0.50, 0.00, 0.50],  # Corn-Soybean
                [0.00, 0.50, 0.50],  # Wheat-Soybean
                [1.00, 0.00, 0.00],  # 100% Corn
                [0.00, 1.00, 0.00],  # 100% Wheat
            ]
        return np.array(actions)
    
    def reset(self):
        """Reset environment to initial state"""
        self.current_step = self.lookback
        self.portfolio_value = self.initial_capital
        self.portfolio_weights = np.array([1.0/self.n_assets] * self.n_assets)
        self.done = False
        return self._get_state()
    
    def _get_state(self):
        """
        Construct state vector:
        - Current portfolio weights
        - Recent returns (lookback window)
        - Rolling volatilities
        """
        if self.current_step < self.lookback:
            recent_returns = np.zeros(self.n_assets)
            rolling_vol = np.zeros(self.n_assets)
        else:
            recent_data = self.returns_data[self.current_step-self.lookback:self.current_step]
            recent_returns = np.mean(recent_data, axis=0)
            rolling_vol = np.std(recent_data, axis=0)
        
        state = np.concatenate([
            self.portfolio_weights,
            recent_returns,
            rolling_vol
        ])
        
        return state
    
    def step(self, action_idx):
        """Execute one time step"""
        # Get new weights from action
        new_weights = self.action_space[action_idx]
        
        # Calculate transaction costs
        weight_changes = np.abs(new_weights - self.portfolio_weights)
        costs = self.portfolio_value * np.sum(weight_changes) * self.transaction_cost
        
        # Update weights
        self.portfolio_weights = new_weights
        
        # Get next period returns
        next_returns = self.returns_data[self.current_step]
        
        # Calculate portfolio return
        portfolio_return = np.dot(self.portfolio_weights, next_returns)
        
        # Update portfolio value
        self.portfolio_value = self.portfolio_value * (1 + portfolio_return) - costs
        
        # Calculate reward
        reward = portfolio_return - (costs / self.portfolio_value)
        
        # Move to next step
        self.current_step += 1
        
        # Check if episode is done
        if self.current_step >= self.n_steps - 1:
            self.done = True
        
        next_state = self._get_state()
        
        return next_state, reward, self.done, {
            'portfolio_value': self.portfolio_value,
            'portfolio_return': portfolio_return,
            'costs': costs,
            'weights': self.portfolio_weights.copy()
        }

print("✅ Portfolio Trading Environment created")
```

### Deep Q-Network Agent

```{python dqn-agent}
#| label: dqn-agent-class

class DQNAgent:
    """
    Deep Q-Network agent for portfolio optimization.
    Uses SimpleNeuralNetwork instead of TensorFlow/PyTorch.
    """
    
    def __init__(self, state_dim, n_actions, learning_rate=0.001, gamma=0.95,
                 epsilon_start=1.0, epsilon_end=0.01, epsilon_decay=0.995):
        self.state_dim = state_dim
        self.n_actions = n_actions
        self.learning_rate = learning_rate
        self.gamma = gamma
        
        # Exploration parameters
        self.epsilon = epsilon_start
        self.epsilon_end = epsilon_end
        self.epsilon_decay = epsilon_decay
        
        # Experience replay
        self.memory = deque(maxlen=10000)
        self.batch_size = 32
        
        # Build networks
        self.model = SimpleNeuralNetwork(
            input_dim=state_dim,
            hidden_dims=[128, 64, 32],
            output_dim=n_actions,
            learning_rate=learning_rate
        )
        
        self.target_model = SimpleNeuralNetwork(
            input_dim=state_dim,
            hidden_dims=[128, 64, 32],
            output_dim=n_actions,
            learning_rate=learning_rate
        )
        
        self.update_target_model()
        
        # Training history
        self.training_history = {
            'episode': [],
            'reward': [],
            'epsilon': [],
            'loss': []
        }
    
    def update_target_model(self):
        """Copy weights from main model to target model"""
        weights, biases = self.model.get_weights()
        self.target_model.set_weights(weights, biases)
    
    def remember(self, state, action, reward, next_state, done):
        """Store experience in replay buffer"""
        self.memory.append((state, action, reward, next_state, done))
    
    def act(self, state, training=True):
        """Choose action using epsilon-greedy policy"""
        if training and np.random.random() < self.epsilon:
            return np.random.randint(self.n_actions)
        
        q_values = self.model.predict(state.reshape(1, -1))
        return np.argmax(q_values[0])
    
    def replay(self):
        """Train on random mini-batch from experience replay buffer"""
        if len(self.memory) < self.batch_size:
            return 0.0
        
        # Sample random mini-batch
        minibatch = random.sample(self.memory, self.batch_size)
        
        states = np.array([t[0] for t in minibatch])
        actions = np.array([t[1] for t in minibatch])
        rewards = np.array([t[2] for t in minibatch])
        next_states = np.array([t[3] for t in minibatch])
        dones = np.array([t[4] for t in minibatch])
        
        # Compute Q-values for current states
        current_q_values = self.model.predict(states)
        
        # Compute target Q-values using target network
        next_q_values = self.target_model.predict(next_states)
        
        # Calculate TD targets
        targets = current_q_values.copy()
        for i in range(self.batch_size):
            if dones[i]:
                targets[i, actions[i]] = rewards[i]
            else:
                targets[i, actions[i]] = rewards[i] + self.gamma * np.max(next_q_values[i])
        
        # Train model
        _ = self.model.forward(states)
        loss = self.model.backward(states, targets)
        
        # Decay epsilon
        if self.epsilon > self.epsilon_end:
            self.epsilon *= self.epsilon_decay
        
        return loss

print("✅ DQN Agent class created")
```

```{python train-agent}
    n_actions=env.n_actions,
    learning_rate=0.001,
    gamma=0.95,
    epsilon_start=1.0,
    epsilon_end=0.01,

# Training parameters

target_update_freq = 10

print(f"\n🚀 Starting DQN Training...")

print(f"   Training data points: {len(train_returns)}")

# Training loop
for episode in range(n_episodes):
    state = env.reset()
    episode_reward = 0
    episode_losses = []
    
    while not env.done:
        # Select action
        action = agent.act(state, training=True)
        
        # Execute action
        next_state, reward, done, info = env.step(action)
        
        # Store experience
        agent.remember(state, action, reward, next_state, done)
        
        # Train agent
        loss = agent.replay()
        if loss > 0:
            episode_losses.append(loss)
        
        episode_reward += reward
        state = next_state
    
    # Update target network periodically
    if (episode + 1) % target_update_freq == 0:
        agent.update_target_model()
    
    # Record history
    agent.training_history['episode'].append(episode + 1)
    agent.training_history['reward'].append(episode_reward)
    agent.training_history['epsilon'].append(agent.epsilon)
    agent.training_history['loss'].append(np.mean(episode_losses) if episode_losses else 0)
    
    # Print progress
    if (episode + 1) % 10 == 0:
        print(f"Episode {episode+1}/{n_episodes} | "
              f"Reward: {episode_reward:.4f} | "
              f"Epsilon: {agent.epsilon:.3f} | "
```
