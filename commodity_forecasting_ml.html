Machine Learning vs Classical Econometrics for Commodity Price Forecasting

A Comparative Study Using Walk-Forward Validation

Author

PAIC Econometrics Research Team

Published

February 17, 2026

Executive Summary

This study compares classical econometric models with modern machine learning approaches for forecasting Soybean futures prices. We implement ARIMA, Random Forest, and XGBoost models using walk-forward validation on daily price data from 2019 to 2026. Our evaluation employs multiple accuracy metrics—RMSE, MAE, MAPE, and directional accuracy—to provide a comprehensive assessment of each model’s forecasting capabilities in the agricultural commodity domain.

NoteResearch Context

Accurate price forecasting is a critical input for portfolio optimization and risk management. This comparative analysis informs model selection decisions within our multi-objective optimization framework, identifying which forecasting paradigm best captures the dynamics of agricultural commodity markets.

1 Introduction

Forecasting commodity prices remains one of the most challenging problems in financial economics. The efficient market hypothesis (Hull 2018) suggests that price changes should be unpredictable, yet practitioners and academics continue to develop models that exploit patterns in historical data. The tension between classical statistical models and modern machine learning approaches has been a subject of vigorous debate (Makridakis, Spiliotis, and Assimakopoulos 2018).

Classical econometric methods, particularly ARIMA models (Box et al. 2015), have a long tradition in time series forecasting. These models provide interpretable parameters, well-defined statistical properties, and established diagnostic tools. However, they rely on linear assumptions and may fail to capture complex nonlinear relationships in the data.

Machine learning approaches, including Random Forests (Breiman 2001) and XGBoost (Chen and Guestrin 2016), offer greater flexibility in modeling nonlinear patterns and interactions between features. However, they may be prone to overfitting, lack interpretability, and require careful feature engineering.

1.1 Literature Review

Ahmed et al. (2010) conducted an empirical comparison of machine learning models for time series forecasting and found that no single method dominates across all datasets. Makridakis, Spiliotis, and Assimakopoulos (2018) analyzed the M3 and M4 competition results, concluding that statistical methods often outperform more complex machine learning approaches for univariate forecasting tasks.

In the commodity forecasting literature, Zhang et al. (2020) proposed a model selection framework incorporating time series features. Guidolin and Pedio (2020) examined whether commodity-specific factors improve forecast accuracy. Timmermann (2006) provided an extensive survey of forecast combination methods.

1.2 Study Objectives

  1. Implement three forecasting models: ARIMA, Random Forest, and XGBoost
  2. Design walk-forward validation: Realistic out-of-sample evaluation with expanding windows
  3. Compare performance metrics: RMSE, MAE, MAPE, and directional accuracy
  4. Visualize forecast results: Actual vs. predicted price trajectories
  5. Assess practical implications: Which model is best suited for commodity portfolio decisions?

2 Methodology

2.1 ARIMA Model

The ARIMA(\(p\), \(d\), \(q\)) model combines autoregressive (AR), differencing (I), and moving average (MA) components:

\[ \Phi(B)(1-B)^d X_t = \Theta(B)\varepsilon_t \]

where \(B\) is the backshift operator, \(\Phi(B) = 1 - \phi_1 B - \cdots - \phi_p B^p\), and \(\Theta(B) = 1 + \theta_1 B + \cdots + \theta_q B^q\).

2.2 Random Forest

Random Forest (Breiman 2001) constructs an ensemble of \(B\) decision trees trained on bootstrap samples with random feature subsets:

\[ \hat{f}(x) = \frac{1}{B}\sum_{b=1}^{B} T_b(x) \]

For time series forecasting, we engineer lagged features \(\{X_{t-1}, X_{t-2}, \ldots, X_{t-L}\}\) as predictors.

2.3 XGBoost

XGBoost (Chen and Guestrin 2016) builds an additive model through gradient boosting:

\[ \hat{y}_i = \sum_{k=1}^{K} f_k(x_i), \quad f_k \in \mathcal{F} \]

The objective function combines a loss function with regularization:

\[ \mathcal{L} = \sum_{i} l(y_i, \hat{y}_i) + \sum_{k} \Omega(f_k) \]

2.4 Walk-Forward Validation

Unlike standard cross-validation, walk-forward validation respects the temporal ordering of data:

  1. Train on window \([1, t]\)
  2. Predict \(\hat{y}_{t+1}\)
  3. Expand window to \([1, t+1]\)
  4. Repeat

This approach prevents information leakage and provides realistic out-of-sample performance estimates.

2.5 Evaluation Metrics

\[ \text{RMSE} = \sqrt{\frac{1}{n}\sum_{t=1}^{n}(y_t - \hat{y}_t)^2} \]

\[ \text{MAE} = \frac{1}{n}\sum_{t=1}^{n}|y_t - \hat{y}_t| \]

\[ \text{MAPE} = \frac{100}{n}\sum_{t=1}^{n}\left|\frac{y_t - \hat{y}_t}{y_t}\right| \]

\[ \text{DA} = \frac{100}{n}\sum_{t=1}^{n}\mathbb{1}\left[\text{sign}(\Delta y_t) = \text{sign}(\Delta \hat{y}_t)\right] \]

3.3 Feature Engineering for ML Models

Code 
def create_features(series, lags=10):
    """Create lagged features for ML models."""
    df = pd.DataFrame({'price': series})
    
    # Lagged prices
    for i in range(1, lags + 1):
        df[f'lag_{i}'] = df['price'].shift(i)
    
    # Rolling statistics
    df['rolling_mean_5'] = df['price'].shift(1).rolling(5).mean()
    df['rolling_std_5'] = df['price'].shift(1).rolling(5).std()
    df['rolling_mean_20'] = df['price'].shift(1).rolling(20).mean()
    df['rolling_std_20'] = df['price'].shift(1).rolling(20).std()
    
    # Returns and momentum
    df['return_1d'] = df['price'].pct_change().shift(1)
    df['return_5d'] = df['price'].pct_change(5).shift(1)
    df['momentum_10'] = df['price'].shift(1) / df['price'].shift(11) - 1
    
    df = df.dropna()
    return df

# Create feature matrix
n_lags = 10

3.7 Performance Evaluation

Code 
def calculate_metrics(actual, predicted, name):
    """Calculate comprehensive forecasting metrics."""
    rmse = np.sqrt(mean_squared_error(actual, predicted))
    mae = mean_absolute_error(actual, predicted)
    mape = np.mean(np.abs((actual - predicted) / actual)) * 100
    
    # Directional accuracy
    actual_direction = np.diff(actual) > 0
    predicted_direction = np.diff(predicted) > 0
    da = np.mean(actual_direction == predicted_direction) * 100
    
    return {
        'Model': name,
        'RMSE': rmse,
        'MAE': mae,
        'MAPE (%)': mape,
        'Dir. Accuracy (%)': da
    }

# Align all predictions to same length
min_len = min(len(arima_predictions), len(rf_predictions), len(xgb_predictions))

metrics_list = [
    calculate_metrics(arima_actuals[:min_len], arima_predictions[:min_len], 'ARIMA(2,1,2)'),
    calculate_metrics(y_test.values[:min_len], rf_predictions[:min_len], 'Random Forest'),
    calculate_metrics(y_test.values[:min_len], xgb_predictions[:min_len], 'XGBoost'),

5.2 Practical Implications

The results of this comparative study have important practical implications:

  1. Model Selection: For one-step-ahead forecasts, the differences between models are often modest. The ARIMA model’s simplicity and interpretability make it attractive for routine forecasting applications (Hyndman and Koehler 2006).

  2. Ensemble Approaches: Given the varying strengths of each model, forecast combinations (Timmermann 2006) may offer improved robustness. A simple average of the three models could reduce forecast variance while maintaining accuracy.

  3. Feature Engineering: The feature importance analysis reveals that recent prices (lag 1-3) and short-term momentum indicators are the most informative predictors, consistent with market microstructure theory.

  4. Directional Accuracy: For trading strategies, directional accuracy is often more important than point forecast accuracy. A model that correctly predicts the direction of price changes more than 50% of the time can generate positive returns (Makridakis, Spiliotis, and Assimakopoulos 2018).

5.3 Limitations

  • Univariate focus: We consider only univariate features; incorporating exogenous variables (weather, exchange rates, inventory reports) could improve accuracy.
  • Static hyperparameters: ML model hyperparameters were not adaptively tuned during the walk-forward process.
  • Single commodity: Results may differ for other commodities with different market dynamics.
  • Transaction costs: Directional accuracy does not account for transaction costs or slippage.

6 Conclusions

This study provides a rigorous comparison of classical and machine learning approaches to Soybean price forecasting. Our key conclusions:

  1. All three models produce forecasts that track the price series reasonably well, with the best model achieving a MAPE within practical limits.
  2. Machine learning models (Random Forest and XGBoost) offer competitive or superior performance, particularly in capturing nonlinear dynamics.
  3. Walk-forward validation provides a realistic assessment of out-of-sample performance, avoiding the overly optimistic results of standard cross-validation.
  4. Feature importance analysis reveals the dominance of short-term price memory, consistent with weak-form market efficiency.

Future work should explore multivariate forecasting incorporating macroeconomic indicators, ensemble methods combining the strengths of different model families, and the application of deep learning architectures such as LSTMs and Transformers.

## Introduction

Forecasting commodity prices remains one of the most challenging problems in financial economics. The efficient market hypothesis [@hull2018options] suggests that price changes should be unpredictable, yet practitioners and academics continue to develop models that exploit patterns in historical data. The tension between classical statistical models and modern machine learning approaches has been a subject of vigorous debate [@makridakis2018statistical].

Classical econometric methods, particularly ARIMA models [@box2015time], have a long tradition in time series forecasting. These models provide interpretable parameters, well-defined statistical properties, and established diagnostic tools. However, they rely on linear assumptions and may fail to capture complex nonlinear relationships in the data.

Machine learning approaches, including Random Forests [@breiman2001random] and XGBoost [@chen2016xgboost], offer greater flexibility in modeling nonlinear patterns and interactions between features. However, they may be prone to overfitting, lack interpretability, and require careful feature engineering.

### Literature Review

@ahmed2010empirical conducted an empirical comparison of machine learning models for time series forecasting and found that no single method dominates across all datasets. @makridakis2018statistical analyzed the M3 and M4 competition results, concluding that statistical methods often outperform more complex machine learning approaches for univariate forecasting tasks.

In the commodity forecasting literature, @zhang2020forecasting proposed a model selection framework incorporating time series features. @guidolin2020forecasting examined whether commodity-specific factors improve forecast accuracy. @timmermann2006forecast provided an extensive survey of forecast combination methods.

## Methodology

### ARIMA Model

The ARIMA($p$, $d$, $q$) model combines autoregressive (AR), differencing (I), and moving average (MA) components:

$$
\Phi(B)(1-B)^d X_t = \Theta(B)\varepsilon_t
$$

where $B$ is the backshift operator, $\Phi(B) = 1 - \phi_1 B - \cdots - \phi_p B^p$, and $\Theta(B) = 1 + \theta_1 B + \cdots + \theta_q B^q$.

### Random Forest

Random Forest [@breiman2001random] constructs an ensemble of $B$ decision trees trained on bootstrap samples with random feature subsets:

$$
\hat{f}(x) = \frac{1}{B}\sum_{b=1}^{B} T_b(x)
$$

For time series forecasting, we engineer lagged features $\{X_{t-1}, X_{t-2}, \ldots, X_{t-L}\}$ as predictors.

### XGBoost

XGBoost [@chen2016xgboost] builds an additive model through gradient boosting:

$$
\hat{y}_i = \sum_{k=1}^{K} f_k(x_i), \quad f_k \in \mathcal{F}
$$

The objective function combines a loss function with regularization:

$$
\mathcal{L} = \sum_{i} l(y_i, \hat{y}_i) + \sum_{k} \Omega(f_k)
$$

### Walk-Forward Validation

Unlike standard cross-validation, walk-forward validation respects the temporal ordering of data:

1. Train on window $[1, t]$
2. Predict $\hat{y}_{t+1}$
3. Expand window to $[1, t+1]$
4. Repeat

This approach prevents information leakage and provides realistic out-of-sample performance estimates.

### Evaluation Metrics

$$
\text{RMSE} = \sqrt{\frac{1}{n}\sum_{t=1}^{n}(y_t - \hat{y}_t)^2}
$$

$$
\text{MAE} = \frac{1}{n}\sum_{t=1}^{n}|y_t - \hat{y}_t|
$$

$$
\text{MAPE} = \frac{100}{n}\sum_{t=1}^{n}\left|\frac{y_t - \hat{y}_t}{y_t}\right|
$$

$$
\text{DA} = \frac{100}{n}\sum_{t=1}^{n}\mathbb{1}\left[\text{sign}(\Delta y_t) = \text{sign}(\Delta \hat{y}_t)\right]
$$

```{python}
def create_features(series, lags=10):
    """Create lagged features for ML models."""
    df = pd.DataFrame({'price': series})
    
    # Lagged prices
    for i in range(1, lags + 1):
        df[f'lag_{i}'] = df['price'].shift(i)
    
    # Rolling statistics
    df['rolling_mean_5'] = df['price'].shift(1).rolling(5).mean()
    df['rolling_std_5'] = df['price'].shift(1).rolling(5).std()
    df['rolling_mean_20'] = df['price'].shift(1).rolling(20).mean()
    df['rolling_std_20'] = df['price'].shift(1).rolling(20).std()
    
    # Returns and momentum
    df['return_1d'] = df['price'].pct_change().shift(1)
    df['return_5d'] = df['price'].pct_change(5).shift(1)
    df['momentum_10'] = df['price'].shift(1) / df['price'].shift(11) - 1
    
    df = df.dropna()
    return df

# Create feature matrix
```

```{python}
#| label: performance-metrics

#| tbl-cap: "Forecasting Performance Comparison"

def calculate_metrics(actual, predicted, name):
    """Calculate comprehensive forecasting metrics."""
    rmse = np.sqrt(mean_squared_error(actual, predicted))
    mae = mean_absolute_error(actual, predicted)
    mape = np.mean(np.abs((actual - predicted) / actual)) * 100
    
    # Directional accuracy
    actual_direction = np.diff(actual) > 0
    predicted_direction = np.diff(predicted) > 0
    da = np.mean(actual_direction == predicted_direction) * 100
    
    return {
        'Model': name,
        'RMSE': rmse,
        'MAE': mae,
        'MAPE (%)': mape,
        'Dir. Accuracy (%)': da
    }

# Align all predictions to same length
min_len = min(len(arima_predictions), len(rf_predictions), len(xgb_predictions))

metrics_list = [
    calculate_metrics(arima_actuals[:min_len], arima_predictions[:min_len], 'ARIMA(2,1,2)'),
    calculate_metrics(y_test.values[:min_len], rf_predictions[:min_len], 'Random Forest'),
    calculate_metrics(y_test.values[:min_len], xgb_predictions[:min_len], 'XGBoost'),
]

metrics_df = pd.DataFrame(metrics_list)

print("=" * 75)
print("FORECASTING PERFORMANCE COMPARISON — SOYBEAN FUTURES")
```

This study provides a rigorous comparison of classical and machine learning approaches to Soybean price forecasting. Our key conclusions:

1. All three models produce forecasts that track the price series reasonably well, with the best model achieving a MAPE within practical limits.
2. Machine learning models (Random Forest and XGBoost) offer competitive or superior performance, particularly in capturing nonlinear dynamics.
3. Walk-forward validation provides a realistic assessment of out-of-sample performance, avoiding the overly optimistic results of standard cross-validation.
4. Feature importance analysis reveals the dominance of short-term price memory, consistent with weak-form market efficiency.

Future work should explore multivariate forecasting incorporating macroeconomic indicators, ensemble methods combining the strengths of different model families, and the application of deep learning architectures such as LSTMs and Transformers.
