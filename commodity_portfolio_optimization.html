NSGA-II Pareto Front Analysis Using pymoo

Author

PAIC Econometrics Research Team

Published

February 17, 2026

Executive Summary

This study applies the Non-dominated Sorting Genetic Algorithm II (NSGA-II) to multi-objective portfolio optimization of agricultural commodity futures. Using daily return data for eight commodities from 2019 to 2026, we simultaneously minimize portfolio risk and maximize expected return to generate a Pareto-optimal frontier. The resulting solutions are compared with equal-weight and minimum-variance benchmark portfolios, providing decision-makers with a comprehensive view of the risk-return tradeoff landscape.

NoteResearch Context

Portfolio optimization is the central application of our econometric research program. This analysis extends classical mean-variance optimization to a multi-objective evolutionary framework, enabling the exploration of the full Pareto frontier rather than a single optimal point.

1 Introduction

Portfolio optimization, first formalized by Markowitz (1952), seeks to construct investment portfolios that achieve the best possible trade-off between risk and return. The classical mean-variance framework reduces this to a single-objective problem through parametric scalarization, but this approach has well-documented limitations including sensitivity to estimation error and a tendency to generate concentrated portfolios (Jagannathan and Ma 2003).

Multi-objective evolutionary algorithms (MOEAs) offer an alternative paradigm that directly generates the Pareto frontier of non-dominated solutions (Deb et al. 2002). The NSGA-II algorithm, in particular, has become a standard tool for multi-objective portfolio optimization due to its efficient non-dominated sorting and crowding distance mechanisms.

1.1 Literature Review

Deb et al. (2002) introduced NSGA-II, which remains one of the most widely cited evolutionary algorithms. Blank and Deb (2020) developed the pymoo Python framework that provides accessible implementations of various MOEAs. In the portfolio optimization context, Chen and Zhou (2022) applied Pareto front evolution methods, while DeMiguel, Garlappi, and Uppal (2009) showed that the naïve 1/N portfolio is surprisingly difficult to outperform.

For agricultural commodity portfolios specifically, Kolm, Tütüncü, and Fabozzi (2014) reviewed 60 years of portfolio optimization challenges, and Leal et al. (2022) applied multi-objective design of experiments to energy asset portfolios.

1.2 Study Objectives

  1. Compute the return-covariance structure of agricultural commodity returns
  2. Implement NSGA-II optimization using pymoo (Blank and Deb 2020)
  3. Generate the Pareto front for the bi-objective risk-return problem
  4. Compare with benchmarks: Equal-weight (1/N) and minimum-variance portfolios
  5. Analyze optimal portfolio weights across the Pareto frontier

2 Methodology

2.1 Portfolio Return and Risk

For a portfolio with weights \(\mathbf{w} = (w_1, \ldots, w_n)^T\):

\[ \mu_p = \mathbf{w}^T \boldsymbol{\mu}, \quad \sigma_p^2 = \mathbf{w}^T \boldsymbol{\Sigma} \mathbf{w} \]

where \(\boldsymbol{\mu}\) is the expected return vector and \(\boldsymbol{\Sigma}\) is the covariance matrix.

2.2 Multi-Objective Formulation

\[ \begin{aligned} \min_{\mathbf{w}} \quad & f_1(\mathbf{w}) = \mathbf{w}^T \boldsymbol{\Sigma} \mathbf{w} \quad \text{(risk)} \\ \max_{\mathbf{w}} \quad & f_2(\mathbf{w}) = \mathbf{w}^T \boldsymbol{\mu} \quad \text{(return)} \\ \text{s.t.} \quad & \sum_{i=1}^{n} w_i = 1, \quad w_i \geq 0 \quad \forall i \end{aligned} \]

2.3 NSGA-II Algorithm

NSGA-II (Deb et al. 2002) proceeds through the following steps:

  1. Initialize a random population of portfolio weight vectors
  2. Evaluate each portfolio’s risk and return objectives
  3. Non-dominated sort the population into Pareto fronts
  4. Assign crowding distance within each front
  5. Select parents via binary tournament (rank, then crowding)
  6. Apply crossover (Simulated Binary Crossover) and mutation (Polynomial Mutation)
  7. Combine parent and offspring populations
  8. Truncate to population size using non-dominated sorting and crowding
  9. Repeat until convergence

3.3 NSGA-II Portfolio Optimization

Code 
from pymoo.core.problem import Problem
from pymoo.algorithms.moo.nsga2 import NSGA2
from pymoo.operators.crossover.sbx import SBX
from pymoo.operators.mutation.pm import PM
from pymoo.operators.sampling.rnd import FloatRandomSampling
from pymoo.optimize import minimize
from pymoo.operators.repair.rounding import RoundingRepair

class PortfolioOptProblem(Problem):
    """Multi-objective portfolio optimization problem."""
    
    def __init__(self, mu, cov_matrix, n_assets):
        super().__init__(
            n_var=n_assets,
            n_obj=2,     # minimize risk, minimize negative return
            n_ieq_constr=0,
            xl=np.zeros(n_assets),
            xu=np.ones(n_assets),
        )
        self.mu = mu.values
        self.cov = cov_matrix.values
    
    def _evaluate(self, X, out, *args, **kwargs):
        # Normalize weights to sum to 1
        row_sums = X.sum(axis=1, keepdims=True)
        row_sums[row_sums == 0] = 1  # avoid division by zero
        W = X / row_sums
        
        # Objective 1: Portfolio variance (minimize)
        risk = np.array([w @ self.cov @ w for w in W])
        
        # Objective 2: Negative return (minimize, because we maximize return)
        neg_return = -W @ self.mu
        
        out["F"] = np.column_stack([risk, neg_return])

# Define problem
problem = PortfolioOptProblem(mu, cov_matrix, n_assets)

# Configure NSGA-II
algorithm = NSGA2(
    pop_size=200,
    sampling=FloatRandomSampling(),
    crossover=SBX(prob=0.9, eta=15),
    mutation=PM(prob=1.0/n_assets, eta=20),
    eliminate_duplicates=True
)

# Run optimization
print("Running NSGA-II optimization...")
res = minimize(
    problem,
    algorithm,
    ('n_gen', 300),
    seed=42,
    verbose=False
)

print(f"Optimization complete!")
print(f"Number of Pareto-optimal solutions: {len(res.F)}")

from scipy.optimize import minimize as sp_minimize

# Equal-weight portfolio
w_eq = np.ones(n_assets) / n_assets
ret_eq = w_eq @ mu.values * 100
risk_eq = np.sqrt(w_eq @ cov_matrix.values @ w_eq) * 100
sharpe_eq = ret_eq / risk_eq

# Minimum-variance portfolio
def min_var_objective(w):
    return w @ cov_matrix.values @ w

constraints = {'type': 'eq', 'fun': lambda w: np.sum(w) - 1}
bounds = [(0, 1) for _ in range(n_assets)]
w0 = np.ones(n_assets) / n_assets

result = sp_minimize(min_var_objective, w0, method='SLSQP',
                     bounds=bounds, constraints=constraints)
w_mv = result.x
ret_mv = w_mv @ mu.values * 100
risk_mv = np.sqrt(w_mv @ cov_matrix.values @ w_mv) * 100
sharpe_mv = ret_mv / risk_mv

# Max Sharpe from Pareto front
idx_max_sharpe = np.argmax(pareto_sharpe)

5 Discussion

5.1 Pareto Front Analysis

The generated Pareto frontier reveals the fundamental trade-off between risk and return in agricultural commodity portfolios. Key observations include:

  • Convexity: The frontier exhibits the expected convex shape, confirming the benefits of diversification across commodities (Markowitz 1952).
  • Benchmark positioning: The equal-weight portfolio typically falls inside the Pareto frontier, confirming that optimized allocations can improve risk-adjusted performance, though DeMiguel, Garlappi, and Uppal (2009) cautioned that estimation error may erode this advantage out-of-sample.
  • Concentration patterns: As portfolios move along the frontier toward higher returns, the allocation becomes increasingly concentrated in high-return commodities.

5.2 Implications for Commodity Investors

  1. Diversification benefits: The minimum-variance portfolio achieves meaningful risk reduction relative to individual commodities, leveraging the imperfect correlations among agricultural futures.
  2. Decision support: The Pareto frontier provides investors with a menu of optimal portfolios, allowing them to select based on their risk preferences without specifying an arbitrary risk aversion parameter.
  3. Dynamic rebalancing: Since return and covariance matrices change over time, the optimization should be periodically updated, motivating a rolling-window implementation.

5.3 Limitations

  • In-sample optimization: The Pareto front is based on historical estimates; out-of-sample performance may differ significantly.
  • Static framework: We assume fixed parameters; a multi-period extension with transaction costs would be more realistic (Rădulescu and Rădulescu 2017).
  • Long-only constraint: Allowing short selling or leverage would expand the feasible set (Jagannathan and Ma 2003).
  • No alternative risk measures: Using CVaR or maximum drawdown instead of variance could produce different optimal allocations.

6 Conclusions

This study demonstrates the application of NSGA-II to multi-objective portfolio optimization in agricultural commodity markets. Our key findings include:

  1. NSGA-II effectively generates a well-populated Pareto frontier, providing investors with a comprehensive view of the risk-return trade-off space.
  2. Optimized portfolios consistently outperform the naïve equal-weight benchmark in terms of Sharpe ratio, though the margin depends on the characteristics of the specific commodity universe.
  3. The minimum-variance portfolio achieves significant risk reduction through diversification across commodities with imperfect correlations.
  4. Weight allocation patterns across the Pareto frontier provide intuitive insights into the roles of different commodities in portfolio construction.

Future work should incorporate multi-period optimization with transaction costs, regime-switching dynamics, and alternative risk measures such as Conditional Value-at-Risk.

\mu_p = \mathbf{w}^T \boldsymbol{\mu}, \quad \sigma_p^2 = \mathbf{w}^T \boldsymbol{\Sigma} \mathbf{w}
$$

where $\boldsymbol{\mu}$ is the expected return vector and $\boldsymbol{\Sigma}$ is the covariance matrix.

### Multi-Objective Formulation

$$
\begin{aligned}
\min_{\mathbf{w}} \quad & f_1(\mathbf{w}) = \mathbf{w}^T \boldsymbol{\Sigma} \mathbf{w} \quad \text{(risk)} \\
\max_{\mathbf{w}} \quad & f_2(\mathbf{w}) = \mathbf{w}^T \boldsymbol{\mu} \quad \text{(return)} \\
\text{s.t.} \quad & \sum_{i=1}^{n} w_i = 1, \quad w_i \geq 0 \quad \forall i
\end{aligned}
$$

### NSGA-II Algorithm

NSGA-II [@deb2002fast] proceeds through the following steps:

1. **Initialize** a random population of portfolio weight vectors
2. **Evaluate** each portfolio's risk and return objectives
3. **Non-dominated sort** the population into Pareto fronts
4. **Assign crowding distance** within each front
5. **Select** parents via binary tournament (rank, then crowding)
6. **Apply crossover** (Simulated Binary Crossover) and **mutation** (Polynomial Mutation)
7. **Combine** parent and offspring populations
8. **Truncate** to population size using non-dominated sorting and crowding
9. **Repeat** until convergence

### NSGA-II Portfolio Optimization

```{python}
#| label: nsga2-optimization
#| code-fold: show

from pymoo.core.problem import Problem
from pymoo.algorithms.moo.nsga2 import NSGA2
from pymoo.operators.crossover.sbx import SBX
from pymoo.operators.mutation.pm import PM
from pymoo.operators.sampling.rnd import FloatRandomSampling
from pymoo.optimize import minimize
from pymoo.operators.repair.rounding import RoundingRepair

class PortfolioOptProblem(Problem):
    """Multi-objective portfolio optimization problem."""
    
    def __init__(self, mu, cov_matrix, n_assets):
        super().__init__(
            n_var=n_assets,
            n_obj=2,     # minimize risk, minimize negative return
            n_ieq_constr=0,
            xl=np.zeros(n_assets),
            xu=np.ones(n_assets),
        )
        self.mu = mu.values
        self.cov = cov_matrix.values
    
    def _evaluate(self, X, out, *args, **kwargs):
        # Normalize weights to sum to 1
        row_sums = X.sum(axis=1, keepdims=True)
        row_sums[row_sums == 0] = 1  # avoid division by zero
        W = X / row_sums
        
        # Objective 1: Portfolio variance (minimize)
        risk = np.array([w @ self.cov @ w for w in W])
        
        # Objective 2: Negative return (minimize, because we maximize return)
        neg_return = -W @ self.mu
        
        out["F"] = np.column_stack([risk, neg_return])

# Define problem
problem = PortfolioOptProblem(mu, cov_matrix, n_assets)

# Configure NSGA-II
algorithm = NSGA2(
    pop_size=200,
    sampling=FloatRandomSampling(),
    crossover=SBX(prob=0.9, eta=15),
    mutation=PM(prob=1.0/n_assets, eta=20),
    eliminate_duplicates=True
)

# Run optimization
print("Running NSGA-II optimization...")
res = minimize(
    problem,
    algorithm,
    ('n_gen', 300),
    seed=42,
    verbose=False
)

print(f"Optimization complete!")
print(f"Number of Pareto-optimal solutions: {len(res.F)}")
```

# Minimum-variance portfolio
def min_var_objective(w):
    return w @ cov_matrix.values @ w

constraints = {'type': 'eq', 'fun': lambda w: np.sum(w) - 1}
bounds = [(0, 1) for _ in range(n_assets)]
w0 = np.ones(n_assets) / n_assets

result = sp_minimize(min_var_objective, w0, method='SLSQP',
                     bounds=bounds, constraints=constraints)
w_mv = result.x
ret_mv = w_mv @ mu.values * 100
risk_mv = np.sqrt(w_mv @ cov_matrix.values @ w_mv) * 100

## Discussion

### Pareto Front Analysis

The generated Pareto frontier reveals the fundamental trade-off between risk and return in agricultural commodity portfolios. Key observations include:

- **Convexity**: The frontier exhibits the expected convex shape, confirming the benefits of diversification across commodities [@markowitz1952].
- **Benchmark positioning**: The equal-weight portfolio typically falls inside the Pareto frontier, confirming that optimized allocations can improve risk-adjusted performance, though @demiguel2009optimal cautioned that estimation error may erode this advantage out-of-sample.
- **Concentration patterns**: As portfolios move along the frontier toward higher returns, the allocation becomes increasingly concentrated in high-return commodities.

### Implications for Commodity Investors

1. **Diversification benefits**: The minimum-variance portfolio achieves meaningful risk reduction relative to individual commodities, leveraging the imperfect correlations among agricultural futures.
2. **Decision support**: The Pareto frontier provides investors with a menu of optimal portfolios, allowing them to select based on their risk preferences without specifying an arbitrary risk aversion parameter.
3. **Dynamic rebalancing**: Since return and covariance matrices change over time, the optimization should be periodically updated, motivating a rolling-window implementation.

### Limitations

- **In-sample optimization**: The Pareto front is based on historical estimates; out-of-sample performance may differ significantly.
- **Static framework**: We assume fixed parameters; a multi-period extension with transaction costs would be more realistic [@radulescu2017multiobjective].
- **Long-only constraint**: Allowing short selling or leverage would expand the feasible set [@jagannathan2003risk].
- **No alternative risk measures**: Using CVaR or maximum drawdown instead of variance could produce different optimal allocations.

## Conclusions

This study demonstrates the application of NSGA-II to multi-objective portfolio optimization in agricultural commodity markets. Our key findings include:

1. NSGA-II effectively generates a well-populated Pareto frontier, providing investors with a comprehensive view of the risk-return trade-off space.
2. Optimized portfolios consistently outperform the naïve equal-weight benchmark in terms of Sharpe ratio, though the margin depends on the characteristics of the specific commodity universe.
3. The minimum-variance portfolio achieves significant risk reduction through diversification across commodities with imperfect correlations.
4. Weight allocation patterns across the Pareto frontier provide intuitive insights into the roles of different commodities in portfolio construction.

Future work should incorporate multi-period optimization with transaction costs, regime-switching dynamics, and alternative risk measures such as Conditional Value-at-Risk.
